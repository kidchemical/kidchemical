## Featured work

### [Escape Purgatory](https://store.steampowered.com/app/1876910/Escape_Purgatory/)

<a href="https://store.steampowered.com/app/1876910/Escape_Purgatory/"><img src="https://cdn.cloudflare.steamstatic.com/steam/apps/1876910/header.jpg" width="460" alt="Escape Purgatory"></a>

Atmospheric horror game from our two-person studio, in Early Access on Steam since
October 2022. Players are trapped in limbo across distinct horror realms, with a story mode
and a replayable Survival Mode. I own the gameplay systems in C#, much of the technical art
pipeline (modeling, rigging, animation, shaders, VFX, lighting), the original music, and the
studio's infrastructure.

`Unity` `C#` `Blender` `Shaders / VFX` `Level design` `Audio`

### Cuttle

A self-hosted AI engineering harness. It puts coding agents (Cursor, Codex, Claude Code and
others) behind one chat interface, with model routing, multi-device workers, evaluations and
development automation. Runs as a daemon with a Flask API, a web/desktop UI and a Discord
bot. Public repo coming soon.

`Python` `Flask` `JavaScript` `Electron` `LLM agents`

### AI & data engineering at Meta

Built AIROC, an AI agent that automates on-call triage and bug-fix workflows; an automated
agent evaluation framework; and reusable agent skills used across teams. Engineering support
for Unidash, Datamate and Presto at scale.

`AI agents` `Analytics infrastructure` `Distributed SQL` `Automation`
